# استثناءات الصلاحيات الفردية للمستخدم

## نظرة عامة

تبويب "الصلاحيات" في صفحة تفاصيل المستخدم يتيح تعديل صلاحيات مستخدم واحد بشكل فردي، بشكل مستقل عن الصلاحيات الافتراضية لدوره، عبر استثناءات (Grant/Revoke) تُطبَّق فوق صلاحيات الدور.

## خطوات التنفيذ - على الويب

1. افتح صفحة تفاصيل المستخدم المطلوب، ثم تبويب "الصلاحيات".
2. تظهر كل الصلاحيات مقسّمة حسب الفئة، مع صندوق اختيار لكل صلاحية يعكس ما إذا كانت فعّالة حالياً لهذا المستخدم.
3. لتبديل صلاحية فردية، اضغط صندوق الاختيار الخاص بها؛ يُنشئ ذلك استثناء منح (grant) أو سحب (revoke) بحسب الحالة الجديدة.
4. الصلاحيات التي لديها استثناء نشط تظهر بجانبها شارة توضح نوع الاستثناء (grant/revoke)، مع رابط "إلغاء الاستثناء" لحذفه والعودة للسلوك الافتراضي للدور.
5. زر "إعادة التعيين إلى الافتراضي" يحذف كل الاستثناءات الفردية للمستخدم دفعة واحدة.

## قواعد التحقق

- لا يمكن للمستخدم تعديل استثناءات صلاحياته الخاصة (يظهر تنبيه "لا يمكنك تعديل صلاحياتك الخاصة" وتكون صناديق الاختيار معطّلة).
- لا تنطبق الاستثناءات على حساب يحمل دور super-admin؛ محاولة تعديلها تُرفض لأن هذا الحساب يملك كل الصلاحيات أصلاً.
- "سحب جميع صلاحيات الدور" (Revoke All) يحذف كل الاستثناءات الحالية ثم ينشئ استثناءات سحب صريحة لكل صلاحية كانت ضمن صلاحيات الدور الافتراضية، بحيث يصبح المستخدم بلا صلاحيات فعلياً.
- "الاستبدال بصلاحيات دور آخر" (Override with Role) ينسخ صلاحيات دور مصدر كاستثناءات منح فردية للمستخدم المستهدف، باستثناء أي صلاحية تتطابق أصلاً مع صلاحيات دوره الحالي (لا تحتاج استثناء).
- بعد أي تعديل على الاستثناءات، تُبطَل ذاكرة الصلاحيات المخزّنة مؤقتاً لهذا المستخدم فوراً.

## الصلاحيات المطلوبة

manage_user_permissions مطلوبة لكل عمليات هذا التبويب: العرض، المنح/السحب الفردي، إعادة التعيين، السحب الكامل، والاستبدال بدور آخر.
